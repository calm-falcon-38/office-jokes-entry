One office joke, written to be read cold: a "Focus Time" calendar block that six colleagues asked to join, until it had an agenda, a chair, and a follow-up meeting. The program writes the joke, a single line of 144 characters, to entry.txt in the output directory, where the bounty's gate (UTF-8 text, 1 to 199 characters) and its pairwise AI judge read it.

## Run it

```sh
node main.ts
```

This writes entry.txt to /output, or to $MAKEFUN_OUTPUT_DIR when that is set.
